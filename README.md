Simple Java Project

A small console Java program that:

asks for your name

asks for your favorite number

prints a greeting

doubles your favorite number

Requirements

Install a Java JDK (Java 17 or newer is fine).

Check that Java is installed:

java -version
javac -version

How to Run

Open a terminal in the project folder.

1. Compile

javac -d out src/Main.java

2. Run

java -cp out Main
